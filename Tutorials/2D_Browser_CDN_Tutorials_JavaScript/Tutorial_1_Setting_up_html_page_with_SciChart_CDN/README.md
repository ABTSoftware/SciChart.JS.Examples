# Tutorial 01 - Including SciChart.js in an HTML Page using CDN

This example provides a template for loading scichart.js from CDN

## Running the Example

Open this folder in terminal and run a server to serve the HTML and JS files.

For example it can be done `python3 -m http.server`.

Then visit http://localhost:8000/ in your web browser!
